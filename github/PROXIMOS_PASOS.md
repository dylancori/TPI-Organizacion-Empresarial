# Actividades para cerrar la reentrega

1. Revisar personalmente el BPMN en un editor (por ejemplo, bpmn.io), y ajustar cualquier detalle conceptual o gráfico.
2. Abrir Issues #1, #2, #3 y confirmar que su contenido refleja lo que se entiende y se propone.
3. Crear un GitHub Project en el repositorio o la cuenta, agregar los tres Issues e incluir columnas **Por hacer**, **En progreso**, **Listo**. No marcar como desarrollada una historia que solo está documentada.
4. Revisar el PR abierto desde feature/reescritura-final-tp4 hacia main.
5. Obtener **revisión real de otra persona**. Si no existe revisor disponible, consultar a la docente si acepta una alternativa; no crear autoaprobaciones.
6. Fusionar el PR solamente después de revisión y validación, y actualizar los enlaces reales del tablero y PR en README y PDF.
7. Completar revisión personal, declaración honesta de IA y entrega del PDF integrador en Moodle.

La carpeta local del ZIP incluye archivos DOCX/PDF de apoyo que todavía deben publicarse o adjuntarse según las condiciones de la entrega.
