## Cómo convertir esta vista en GitHub Projects
1. Iniciar sesión en GitHub con **dylancori**.
2. Entrar a https://github.com/users/dylancori/projects y crear un proyecto de tipo **Board** denominado `TPI TechLogix - Backlog`.
3. Importar los Issues #1, #2 y #3 del repositorio y configurar Status con **Por hacer**, **En progreso** y **Listo**.
4. Dejar las tres HU en Por hacer hasta que exista actividad técnica verificable; mover una a En progreso cuando se comience su trabajo.
5. Copiar la URL pública real al README y a la primera página del PDF. Confirmar que el proyecto es visible sin iniciar sesión.

El autor debe comprobar la visibilidad real y realizar esos pasos desde GitHub, pues la conexión actual no ofrece creación de GitHub Projects.
