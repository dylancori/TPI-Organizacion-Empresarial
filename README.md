## Caso y alcance
TechLogix Solutions es una empresa **ficticia** de soluciones informáticas. La propuesta inicial (Entregas 1 y 2) es un módulo de pruebas automatizadas y **CI/CD**. La Entrega 4 modela el proceso de gestión de incidentes como fuente de problemas a corregir y como retroalimentación para esas pruebas. **No existe una aplicación terminada ni un despliegue productivo demostrable**; el repositorio documenta un proyecto académico.

## Contenidos efectivamente presentados en las entregas previas
1. **Organización y enfoque sistémico:** empresa, misión, visión, entradas, procesos, salidas, entorno, feedback y módulo propuesto.
2. **Diagnóstico y planeación:** matriz FODA, objetivos medibles y Gantt de diez semanas del módulo CI/CD.
3. **Estructura formal y datos:** organigrama del área de desarrollo y diccionario preliminar de las entidades Cliente, Proyecto e Incidente.
4. **Procesos, colaboración y control:** modelado BPMN de atención de incidentes con QA/CI-CD, tres historias de usuario, indicadores propuestos y evidencia de Git/GitHub.
